# Dream prompt assets

These prompt assets adapt the `fengyincheng/DreamSea` prompt system for Stone
Memory's thread-scoped feelings input.

- `common-core.md` contains the shared contract and runtime placeholders.
- Each standard dream type has exactly one matching `<type>.md` strategy file.
- Dreammaker names and private-project character names are intentionally omitted.
- Prompt prose belongs in this directory. JavaScript may only select, load, interpolate,
  and validate these assets.
