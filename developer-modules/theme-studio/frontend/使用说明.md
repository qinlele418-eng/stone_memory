# Stone Memory 主题工作台使用说明

## 打开

1. 在项目根目录执行 `npm start`，或执行 `node bin/stmem web`。
2. 打开 Stone Memory Web 页面，进入开发者模式。
3. 点击“主题工作台”实验模块。

## 编辑主题

- 在“主题”区域选择 Stone Memory Original、松烟青或自定义主题。
- “界面色 → 强调色”控制按钮、选中态和交互强调。
- “记忆花色”控制活动日历的浅色与深色花色。
- “状态色”对应正常、警告、信息、冲突、融合和危险状态。
- 颜色、圆角和阴影支持直接编辑；阴影也支持按偏移、模糊、扩散、颜色和透明度拆分编辑。
- Logo 可上传、预览和移除，并随主题 JSON 导出。
- 点击“保存主题”立即应用并保存；点击“恢复原版”恢复 Stone Memory Original。

## 导入与导出

- “导出当前主题”生成主题 JSON，可用于备份或分享。
- “导入主题”支持 version 3，也兼容 version 1/2 文件。
- 旧版本主题导入后会合并当前契约默认值，并保存为 version 3 格式。
- 主题只保存在浏览器的 `stone-memory-ui-theme-v1` 与 `stone-memory-ui-themes-v1` 中，不写入 SQLite 或记忆数据。

## 停用与回滚

- 临时停用：删除 `src/web/public/index.html` 中的 `/theme-studio/bootstrap.js` script 标签。
- 完整移除：删除 `src/web/public/theme-studio/` 目录。
- 停用模块不会删除浏览器已有主题偏好；重新挂载模块后仍可发现这些偏好。

## 本地验证

```text
node test/theme-studio-integration.test.js
npm run test
```

主题工作台只影响浏览器 UI 层，不改变记忆体、线程、API 或数据库结构。
