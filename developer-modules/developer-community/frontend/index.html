这个 API 用来做什么？

配置后，AI 会阅读 PR/Issue 的正文、文件列表、提交记录和 CI，告诉你它实现了什么、改了哪些地方、有什么值得做，以及有哪些修改建议。AI 只负责阅读和建议，不会替你 Star、回复、合并或修改代码。

三项全部留空＝原文模式；要启用 AI，接口地址、模型和 Key 必须全部填写。原文模式仍会展示 GitHub 返回的 PR/Issue 原文、文件增删、提交记录、讨论和 CI。
