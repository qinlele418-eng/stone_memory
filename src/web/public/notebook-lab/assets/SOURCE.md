# Sentence-book assets

- blossom-v1.png: AI-generated watercolor floral ornament contributed with this sentence-book interface.
- frame-rail.svg and gold-flecks.svg: decorative vector assets contributed with the interface.
- huiwen-mincho-v1.woff2 and kinghwa-oldsong-v2.woff2: WOFF2 conversions of Huiwen Mincho v1 and KingHwa OldSong v2 by Terri Wang. Original source mirror: https://github.com/cntrump/imitation_typeface_fonts . Original copyright and permission text is included in FONT-LICENSE.md.
