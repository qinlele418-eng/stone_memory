01 · 边界

只写自己的模块

不得直接修改核心 app.js，不得另建数据库写入链，也不得硬编码用户路径、端口或线程标识。

02 · 复用

核心能力走正式接口

主题、当前记忆体、导航和请求由模块运行时提供；业务写入复用 SM 的 API、CLI 或服务层。

03 · 验收

桌面与移动端同验

模块必须在自定义主题、窄屏、接口失败和未绑定记忆体状态下保持可理解、可退出。
